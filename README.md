## 当前公开版本：5.5.0

文字冒险与横屏地图探索可以在设置中切换，共用人物、任务和行动结果。文字模式的区域简图与实景读取同一份场景数据，未获知的内部区域和隐藏目标按可见性规则保留。

目前覆盖 **107 个规则地点、112 个场景视图**。本轮新增 38 处地图覆盖，包括维斯佩、同盟初见及周边、死亡高原和五座新总部。客房等子场景可共用规则地点，因此场景视图数高于地点数；交通、任务和入场资格仍需实际取得。

七大主世界总部沿用正式名称：白银圣廷、万镜穹顶、极乐深渊、预言家协会总部、苦痛圣堂、万魂归墟、冒险者公会总部。接洽、研究、任职和训练按各组织的实际许可开放，地狱途径不计入这七处。

探索默认保留二维，客房、旅店及对应住宅模板提供固定视角的 2.5D 实验呈现。战场适配覆盖六种环境主题、22 个战场配置，并统一了一批单位图像。人物仍采用二维图像，游戏内保留二维和画质切换入口；本版没有完整三维角色、自由旋转或高低差战斗规则。另调整了摇杆持续输入、楼梯阻挡与落点、交锋朝向及仓库展示。

八条超凡途径已开放六阶。委托、书报、线索、职业、公会、伙伴关系和日常生活延续现有规则。排行榜默认关闭，玩家可自行上传或撤下；单机存档留在本机，榜单不保证防止离线修改。

5.5.0 的最终 APK 已完成构建与签名核对，未逐设备、逐地图或逐剧情通关验证。触控手感、战场表现与长线流程仍需实际游玩反馈。**6.0.0 尚在开发**，其 HUD 调整、城镇生活与局部光照、六主题战场美术返工不包含在本次 5.5.0 中。

## 安装与继承

从[最新公开发行页](https://github.com/JXZ666/echoes-of-the-abyss/releases/latest)下载安装包，具体改动以各版本说明为准。网页与 APK 不自动同步存档。

升级前先导出迁移包，尽量覆盖安装，避免卸载导致未备份人物丢失。迁移包可在网页与 Android 之间导入，不包含 API Key。受支持旧档保留原文件和备份，旧锁定行动按原规则接续。

高 AI 模式需自行配置可用的服务商与 Key；网络故障时仍可使用本地预设行动。游戏面向成年人，关系内容保持成年、自愿、非露骨，可在设置中关闭。
