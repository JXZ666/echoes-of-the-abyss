## 4.0.0《第三卷·大远征》

八条超凡途径开放六阶，各有不同的战斗、辅助与被动能力；消化时间、真实实践和仪式准备共同决定成长。三座新镇连接三国旧有旅路，第三卷第一幕提供不同的出发方式。

战场会按实地生成障碍，部分物件可破坏，行动前能查看规则预览；可手动指挥、配置常用轮盘或开启自动接管。横屏重排行动区与人物信息，棋子、立绘和地点原画各有展示入口。

城镇布告栏汇集委托和公开消息，书报提供可查阅的线索。任务可以折叠，常用术语和已经获知的线索关系可在游戏内查看。职业、公会、组织任职、同伴关系与日常生活沿着各自的实际约定推进。

排行榜由玩家自行决定是否参加：默认关闭，手动上传或撤下，展示昵称、公共剧情完成度、途径与阶位的每日前50名。单机存档仍在本机；这是玩家交流榜，不保证防止离线修改。
