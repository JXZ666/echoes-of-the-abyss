## 当前公开版本：6.0.0

本版补齐23处既有主世界地图，目录覆盖130个规则地点、135个场景视图。文字简图与地图探索共同读取场景，交通、事件、商店和试炼仍有各自的实际条件；地狱及动态裂隙内部继续保留独立玩法。

- 林地、道路、港口、工坊、遗迹、高原六主题战场重新制作，整理摆件接地、占地和短横屏取景。行动顺序可定位单位，保留全景和二维入口。
- 战斗底栏改为移动、攻击、防御、技能、更多、结束回合，物品归入更多。教学可前后翻、收起和关闭，定位目标时避让。
- 玩家和伙伴的普攻、普通招式对同一目标连续未中时，公开命中校准每次+1、上限+3；命中或切换攻击目标后清空，不改自然1/20或伤害骰。
- 探索状态栏避让目标，对话行动分类与分页；已知世界书词条可在地图对话中点开，仓库和便携行囊共用人物展示。
- 按场景用途安排聊天、工作和桌边活动，桌面酒食与牌具对应；室内、户外和地下独立照明，酒馆夜间保留暖灯。
- 更新骨色暗金骰台和真实成果提示。动画只展示已保存的结果，读档不重复结算或补发奖励。

开发方完成必要回归、网页与Android构建、原签名和资源核对。最终APK由作者自行实机试玩，未宣称逐设备或全部剧情通关；立体显示可回退二维。

## 安装与继承

从[最新公开发行页](https://github.com/JXZ666/echoes-of-the-abyss/releases/latest)下载安装包，具体改动以各版本说明为准。网页与 APK 不自动同步存档。

升级前先导出迁移包，尽量覆盖安装，避免卸载导致未备份人物丢失。迁移包可在网页与 Android 之间导入，不包含 API Key。受支持旧档保留原文件和备份，旧锁定行动按原规则接续。

高 AI 模式需自行配置可用的服务商与 Key；网络故障时仍可使用本地预设行动。游戏面向成年人，关系内容保持成年、自愿、非露骨，可在设置中关闭。
